# Phase 6R 阶段总结：首页视觉层级 polish + 今日页面视觉统一

## 1. 阶段背景

Phase 6R 在 Phase 6O（状态筛选、离线文案、复习动作语义）收口完成后，对首页和今日相关页面做最小视觉 polish。目标：

- 首页任务区与卡片库区增加轻量视觉分隔；
- 首页今日任务看板增强入口感；
- 今日复习情况页、今日复习内容页统一到首页暖绿轻学习视觉体系；
- 全阶段只改 wxss，不改业务逻辑。

## 2. 已完成子阶段

### 6R-1：首页视觉层级审查

只读审查了 app.wxss 和全部页面的 wxss 文件。

审查结论：
- app.wxss 中已有 8 个 CSS 变量（--bg-color-page 等），但各页面 wxss 均未引用，处于孤立状态；
- 首页 wxss 最大（3168 行 / 60KB），经历多轮覆盖累积；
- 复习页使用偏亮绿色调，今日复习情况页使用蓝+亮绿，与首页暖绿方向不一致；
- 无 P0/P1 风险，适合做最小视觉 polish。

### 6R-2：首页视觉层级 polish（commit: `fad11ec`）

修改文件：`pages/index/index.wxss`

改动：
1. **今日任务看板入口感增强** — `.status-overview-arrow` 从文本 `›` 改为 48rpx 圆形浅绿底衬图标按钮，与代码库中已有的 `review-cta-arrow` 设计模式一致。

## 5. 验收建议

建议在真实微信环境中验证以下场景：

**首页：**
- 0 张卡 → 引导添加页面正常
- 有卡片 → 任务看板 + 主按钮 + 筛选 + 卡片库正常
- pending 卡 → 弱提示正常
- 后端关闭 / 离线 → 错误态正常

**今日复习情况页：**
- 进行中态 → 进度条 + 统计 + 继续复习按钮
- 完成态 → 结果分布 + 继续复习按钮
- 离线态 → 离线文案 + 按钮禁用
- 四个入口按钮跳转正确

**今日复习内容页：**
- 空态 → 提示正常
- 有记录 → 卡片展示正常
- 编辑返回 → 刷新正常
- 离线有缓存 / 离线无缓存 → 文案正确
