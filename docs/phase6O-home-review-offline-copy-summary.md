## 3. 当前产品规则

本阶段明确下来的规则：

1. 离线新增卡片允许 pending，保存时显示"已先保存，联网后自动更新"；
2. 离线正式复习暂不支持，断网反馈不推进、不完成、不进入同步页；
3. pending / local-only 卡片不进入正式复习；
4. 复习反馈必须以后端成功为准，网络失败时留在当前卡片；
5. 用户可见文案不暴露以下技术词：待同步 / 同步进度 / 同步成功 / actionQueue / 队列 / 离线缓存 / 本地；
6. 今日复习内容页可以在离线时显示最近保存的内容；
7. 历史复习内容页离线时不伪装成 0 条记录，直接告知无网络。
