# English Study Miniapp 视觉设计准则

## 1. 设计目标

真实小程序页面以 `pages/index/index` 当前首页为视觉基准。以阅读、明确的主操作与可恢复的学习流程为优先，形成统一的低饱和液态玻璃界面。2026-09-21 产品审查更新取代此前仅调整视觉的批次限制。

关键词：透亮干净、柔和自然、低饱和、高级但克制、简约但有层次、轻微科技感、阅读优先。

## 2. 页面气质

- 全站共用一张氛围图，不按页面各画一张。页面差异靠内容和纸面透明度，不靠换壁纸。
- 列表、阅读和表单区域优先使用轻透的浅绿玻璃面，保留足够文字对比度；卡片左滑露出操作时再提高前景不透明度。
- 复习页不再叠加 CSS 树枝/叶子，只保留照片氛围，并且背景固定、不随内容滚动。
- 导航、英文阅读、答题和表单延续轻玻璃感。iOS 与 Android 均应在无模糊效果时保持清晰，不增加大面积实时模糊。
- 想记住、播放、选中态等控件可以保留浅色实底，方便点按；常态列表行保持通透，滑出操作时强化前景。
- 玻璃边界依靠细白描边和轻阴影建立，不依靠厚重灰边、内发光白底或强烈投影。
- 页面留白应形成节奏。避免多个等权方块堆叠，优先使用清晰的主内容、次内容和辅助信息层级。

## 3. 色彩

- 主文字：`#153729` / `#173b2c`
- 次文字：`#60756a`
- 弱提示：`#87978e`
- 主绿色：`#47765d`，只用于主要动作、选中态和进度。
- 页面底色：`#eff6f1`
- 玻璃描边：`rgba(255, 255, 255, 0.72–0.90)`
- 危险操作保留低饱和红色，只在错误和删除场景使用。

## 4. 字体和信息层级

- 中文使用系统字体：`PingFang SC`、`Microsoft YaHei`。
- 英文标题和核心学习内容使用 `Baskerville`、`Palatino Linotype`、`Georgia` 回退栈，不引用小程序本地字体文件。
- 页面标题不使用过粗字重；正文保持足够行高，长英文允许自然换行。
- 全大写英文眉题仅作为小面积辅助信息，增加字间距，不与正文争夺注意力。

## 5. 圆角和间距

- 大型主面板：40–50rpx 圆角。
- 普通内容卡片：28–38rpx 圆角。
- 输入框、筛选器：24–32rpx 圆角。
- 胶囊按钮：999rpx 圆角。
- 页面左右安全留白通常为 28–40rpx；卡片内部留白通常为 22–34rpx。
- 同层元素间距保持稳定，避免为了填满屏幕而随意拉伸。

## 6. 组件规则

### 自定义 TabBar

- 三个一级页使用自定义玻璃底栏，不再使用原生白底栏。
- 底栏半透明，叶子背景可以从后方透出；选中态是滑动的浅绿色胶囊。
- 一级页切换时内容有 250–400ms 进入过程，禁止闪切。

### 主按钮

- 深鼠尾草绿半透明底，白色文字，胶囊形。
- 同一页面只突出一个主要动作。

### 次按钮与筛选器

- 透明或浅玻璃底，细白描边。
- 选中态使用主绿色；未选中态保持安静。

### 内容卡片

- 信息层级顺序：英文内容 → 中文理解 → 来源/状态。
- 英文内容是视觉主角，辅助标签不应抢占第一视线。
- 列表卡片不重复加入无意义装饰。

### 表单

- 表单整体是一块连续玻璃纸面；字段通过留白和细分隔线组织，避免“方块套方块”。
- 输入区保持透明、可辨识，焦点态只做轻微绿色高光。

### 状态页

- loading、empty、error 延续同一背景和字体。
- 错误使用克制的红色提示，不改变重试等原有行为。

## 7. 动效

- 页面进入和切换控制在 250–400ms。
- 按压反馈约 300ms，使用轻微缩放、亮度或向外扩散的水波感。
- 首页主卡片按下时轻微缩小并亮起边沿，松手后回到原状。
- 禁止持续漂浮、频繁闪烁、强弹跳和影响阅读的循环动画。
- 尊重 `prefers-reduced-motion`，减少动画时不影响功能。

## 8. 页面适配

- 顶部内容避开微信胶囊按钮与安全区。
- 底部主要操作避开原生 TabBar、Home Indicator 和批量操作栏。
- 页面只允许需要的滚动方向；长列表保持纵向滚动和文字截断策略。
- 小屏优先保证内容完整，装饰可以弱化或隐藏。

## 9. 前端修改白名单

本轮只允许修改：

- `pages/**` 下真实页面的 `.wxml`、`.wxss`；不修改 `pages/demo/**`。
- `app.wxss` 中的共享视觉样式。
- `assets/home/**` 中已有的视觉资源引用。当前氛围图为 `home-ambient-v6.jpg`。叶影铺进卡片后方，画布使用接近手机的 9:19.5 比例，避免真机 aspectFill 把右侧叶子裁掉。
- 本准则文档。

未经产品需求确认，不修改页面 JavaScript、`utils/**`、接口参数、存储结构、登录、AI、TTS、复习判定、复习次数、卡片状态和后端工程。

## 10. 统一验收标准

- 所有真实页面改完后统一在微信开发者工具中编译和巡检，不按单页拆分验收。
- 核查首页、复习、我的英语、添加、素材、词汇书、详情、历史、设置和关于页面的视觉一致性。
- 核查长英文、空状态、加载状态、错误状态、选中态、答对/答错态和底部安全区。
- 核查控制台无新增 WXML/WXSS 编译错误、本地资源加载错误和无效选择器。
- 视觉验收不代替业务验收；本轮只确认现有交互入口没有因样式修改而丢失或被遮挡。
