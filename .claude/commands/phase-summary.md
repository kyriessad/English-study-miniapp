# phase-summary

写阶段总结文档。

## 要求

1. 使用简洁中文。
2. 包含阶段目标、提交号、修改文件、最终语义、验收结果、未做事项、下一步。
3. 不夸大。
4. 不写无关技术细节。
5. 默认保存到 docs/<phase-name>-summary.md。
6. 写完运行 git diff --check。
7. 不提交，除非用户明确要求。
